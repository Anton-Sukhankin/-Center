# AIShtab

AIShtab — прототип личного кабинета для централизации проектной информации, работы с событиями и инцидентами, анализа метрик и поддержки управленческих решений.

## Документация

- `docs/README.md` — основной маршрутизатор и реестр документации.
- `docs/documentation-standards.md` — правила классификации, связности и жизненного цикла документов.
- `PROJECT_GUIDELINES.md` — общие правила проекта.
- `AGENTS.md` — рабочая инструкция для AI-агентов.
- `docs/system-overview.md` — корневая продуктовая спецификация.
- `docs/system-compliance-matrix.md` — состояние текущего прототипа относительно продуктовой модели.

## Активная реализация

Основная версия AIShtab работает на React. Корневой [index.html](index.html) подключает [React-вход](react/main.jsx).

```powershell
npm ci
npm run dev
```

Локальный адрес — `http://127.0.0.1:5173/`. Команда `npm run build` формирует `dist/`, а `npm run preview` запускает проверку собранной версии на `http://127.0.0.1:4173/`. Компоненты, общие данные и браузерная проверка описаны в [паспорте React-прототипа](react/README.md).

Рабочий React-прототип открывается по корневому адресу Vite. [HTML-полигон](playground.html) содержит только последний эксперимент. После переноса решения в React при следующей задаче содержимое полигона заменяется, адрес сохраняется.

Если работающего сервера нет, запустите `npm run dev` в терминале локального проекта. При занятом порте `5173` можно выбрать свободный порт, например `npm run dev -- --port 5174`. Если команда из изолированной сессии сообщает `EACCES` при запросе к `127.0.0.1`, проверьте адрес работающего сервера непосредственно во встроенном браузере. Доступ браузера к работающему локальному серверу проверяется отдельно от доступа команд из изолированной сессии.

[Опубликованный прототип AIShtab](https://aishtab-interface-0904.armadaopera.chatgpt.site/) открывает ранее развернутую версию. [Конфигурация Sites](.openai/hosting.json) указывает `dist/` для отдельного выпуска.

Роли слоев описаны в [паспорте приложения](src/app/README.md), [паспорте данных](src/data/README.md) и [паспорте UI](src/ui/README.md). Пользовательские сценарии и компоненты описаны в README внутри `src/features/` и `src/components/`.

`legacy/isolated/` не входит в активный прототип и обычный обзор проекта.

## Восстановление нативной версии

Последний нативный прототип сохранен под Git-меткой `aishtab-native-final` на ревизии `eb26bdf`. Чтобы открыть его в отдельной рабочей папке:

```powershell
git worktree add --detach ../AIShtab-native aishtab-native-final
Set-Location ../AIShtab-native
node scripts/serve-prototype.mjs 8011
```

Адрес исходной версии — `http://127.0.0.1:8011/`. Для старого входа иконки Lucide и шрифты подключаются с CDN. При контрольной проверке восстановления браузер получил локальную копию Lucide.

## Проверка документации

Структурная проверка выполняется без внешних зависимостей:

```powershell
node scripts/check-documentation.mjs
node --test scripts/check-documentation.test.mjs
```

Checker проверяет ссылки, реестры, локальные README, visual assets, пути к реализации и обязательные контракты пилотных сложных областей. Он только сообщает нарушения и не изменяет документы автоматически.
