# NavigationTreeItem

## Назначение

`NavigationTreeItem` отображает одну строку левого дерева навигации: бизнес-юнит, проект или очередь.

## Код

- `navigation-tree-item.js`.

## Входные параметры

Компонент получает:

- уровень вложенности;
- тип узла;
- идентификатор узла;
- название;
- состояние выбранности;
- наличие дочерних элементов;
- состояние раскрытия;
- идентификатор родительского проекта.

## Параметры строки по уровню

Левое структурное дерево является базовым фильтром системы. Строка дерева должна показывать данные, достаточные для выбора контекста и понимания уровня.

| Уровень | Параметры строки |
| --- | --- |
| Бизнес-юнит | Название бизнес-юнита, общая картинка или визуальная метафора, руководитель бизнес-юнита, наличие дочерних проектов. |
| Проект | Название проекта, фотография или миниатюра, текущая стадия строительства, кластер или класс проекта, регион, руководитель проекта. |
| Очередь | Номер или название очереди, технико-экономические параметры, общая продаваемая площадь, стадия разрешительной документации: до РНС, РНС получено, ЗОС или РВЭ. |

Эти параметры могут отображаться не полностью в каждой визуальной версии строки, но должны быть доступны компоненту или связанному слою данных, чтобы выбранный узел корректно обновлял шапку, ленту событий и показатели.

## Пользовательский путь

Пользователь выбирает бизнес-юнит, проект или очередь. Этот выбор вызывает `setActiveEntity`, после чего меняются шапка, события, строительные показатели и финансовые метрики.

## Зависимости

Компонент использует:

- `window.SCenterUI`;
- `window.SCenterComponents.renderNavigationTreeItem`;
- `window.SCenterComponents.renderNavigationTreeItemClose`;
- `window.setActiveEntity`;
- `window.toggleTreeNode`.

## Когда обновлять документ

Документ нужно обновлять, если меняется структура дерева, состояния строки, логика раскрытия, визуальная индикация уровня или пользовательский сценарий выбора контекста.
