# Готовая команда для агента целевого проекта

Скопируйте текст ниже и при необходимости укажите расположение кнопки открытия и API ассистента.

> В корень проекта добавлена папка `chat-transfer-package`. Интегрируй содержащийся в ней ИИ-чат в текущее приложение. Сначала изучи `chat-transfer-package/README.md`, `docs/integration.md`, `docs/behavior-contract.md` и `tests/interaction-checklist.md`.
>
> Сохрани `src/AIChat.js` и `src/AIChat.css` как переносимое ядро: не воспроизводи интерфейс заново и не подменяй его компонентами целевого проекта. Создай отдельный адаптер целевого проекта по образцу `adapters/scost-prototype-adapter.js`. Через него подключи текущий контекст, API сообщений, хранилище истории, вложения, действия и закрытие конфликтующих панелей.
>
> Не подключай `adapters/scost-prototype-adapter.*` в целевом проекте, если в нём нет исходной структуры S.Cost. `src/demo-provider.js` используй только до подключения реального API.
>
> После интеграции пройди весь `tests/interaction-checklist.md`. Проверь отсутствие ошибок консоли, стандартную/минимальную/максимальную ширину, узкий viewport и все диалоги. Любые необходимые отличия от исходного компонента сначала перечисли отдельно; не вноси их скрытно.
