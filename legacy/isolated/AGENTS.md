# AGENTS.md

## Назначение области

`legacy/isolated/` содержит модули, которые сохранены для возможного будущего возврата, но исключены из активной структуры прототипа S.Center.

## Правило для агентов

Агентам и субагентам нельзя читать, индексировать, анализировать или использовать файлы из этой области при обычном обзоре проекта.

Открывать эту область можно только при явной команде пользователя:

- восстановить изолированный модуль;
- провести аудит конкретного изолированного модуля;
- подготовить план обратной интеграции;
- сравнить текущую активную реализацию с сохраненной изолированной версией.

Если такой команды нет, считай содержимое `legacy/isolated/` неактивным архивом, а не частью текущей архитектуры.

## Правило возврата

Перед возвратом любого модуля из этой области нужно:

1. Сформировать отдельный план интеграции.
2. Проверить конфликты с активными компонентами.
3. Обновить `index.html`, `src/app/README.md`, `docs/component-map.md`, `docs/component-impact-map.md` и `docs/system-compliance-matrix.md`.
4. Проверить синтаксис JS и пользовательские сценарии, которые модуль затрагивает.
