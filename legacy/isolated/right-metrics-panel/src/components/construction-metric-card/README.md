# ConstructionMetricCard

## Назначение

`ConstructionMetricCard` отображает одну карточку строительного показателя в правой панели.

## Код

- `construction-metric-card.js`.

## Источник данных

Карточка получает готовые значения из `appData.getConstructionMetricsForContext(activeContext)`.

Базовая расчетная единица — очередь. Проект агрегирует очереди, бизнес-юнит агрегирует проекты.

## Отображаемые данные

Текущий интерфейс использует две карточки:

- длительность проекта;
- объем проекта.

Каждая карточка является статичным цифровым срезом выбранного структурного контекста и отображает текущие значения без длинного графика.

Обязательные параметры:

| Параметр | Назначение |
| --- | --- |
| Название показателя | Например `Длительность проекта` или `Объем проекта`. |
| Фактическое или текущее значение | Актуальное значение на текущий отчетный месяц или выбранный контекст. |
| Плановое значение | Бюджетное или плановое значение показателя. |
| Прогнозное значение | Ожидаемое значение на конец проекта или периода. |
| Отклонение | Разница между фактом и планом, а также динамика относительно предыдущего месяца, если доступна. |
| Визуальная иконка | Быстрая ассоциация с типом показателя, например календарь для длительности или куб для объема. |

## Пользовательский путь

Пользователь выбирает бизнес-юнит, проект или очередь в левом дереве. После выбора значения строительных показателей в правой панели должны измениться.

## Зависимости

Компонент использует:

- `window.SCenterUI`;
- `window.SCenterComponents.renderConstructionMetricCard`;
- `src/app/app.js` для передачи расчетных значений.
