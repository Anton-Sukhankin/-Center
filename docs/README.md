# Документация S.Center

## Назначение

Этот файл является постоянным маршрутизатором и реестром документации. Он отвечает на три вопроса: где искать источник истины, какой статус имеет каждый документ и куда встроить новый документ без создания параллельной спецификации.

Правила классификации и жизненного цикла находятся в `documentation-standards.md`. Общие правила проекта находятся в `../PROJECT_GUIDELINES.md`, а инструкция для AI-агентов — в `../AGENTS.md`.

## Обозначения реестра

- `основной` — источник истины в своей области;
- `дополняющий` — уточняет основной источник, но не переопределяет его;
- `рабочий` — используется для сбора вопросов или выполнения ограниченной задачи;
- `доказательный` — подтверждает проверку или визуальное решение;
- `ненормативный` — предоставляет контекст, но не является заданием;
- `текущий`, `целевой`, `переходный`, `история` — временной слой;
- `проверить`, `уточнить`, `переместить`, `архивировать` — действия выполняются по `plans/project-cleanup-audit-plan.md` и его профильным дочерним планам, а не автоматически.

## Расширение реестра

При добавлении документа в этом файле должна появиться строка с его классом, временным слоем, статусом и следующим действием. Если существующая группа не подходит, сначала расширяется `documentation-standards.md`, затем создается новая группа реестра. Новая классификация не должна менять смысл старых классов без отдельной миграции всех затронутых документов.
