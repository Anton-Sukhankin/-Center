# Компонент `construction-object-selector`

## Назначение

Компонент отображает повторяемую группу карточек выбора объекта строительства для «Цифровой шахматки» и раздела «Объекты». Он не хранит выбранный объект и не объединяет feature-specific данные: матричная геометрия шахматки и паспортные параметры объектов поступают через разные адаптеры.

Компонент реализован как classic-script/IIFE, не использует React и регистрирует функции в существующем `window.SCenterComponents`.

## View model карточки

`renderConstructionObjectSelector(cards, options)` принимает массив:

| Поле | Назначение |
| --- | --- |
| `id` | Стабильный идентификатор объекта. |
| `name` | Название объекта. |
| `typeLabel` | Пользовательское название типа. Используется как fallback, если нет параметров для description. |
| `descriptionLabel` | Верхний description под названием объекта. В «Шахматке» и «Объектах» сюда передаются параметры объекта, ранее показанные в нижней meta-строке карточки. |
| `icon` | Имя иконки Lucide. |
| `progressPercent` | Готовность карточки в диапазоне `0–100`. |
| `deviationLabel` | Feature-specific подпись отклонения. |
| `deviationTone` | `behind` или `on-plan`. |
| `metaLabel` | Feature-specific структурная подпись и fallback для `descriptionLabel`. |

Stable identity должна поступать из `window.constructionObjectsData`; готовность, отклонение и структурная подпись остаются частью адаптера конкретной feature.

## Публичный API

- `window.SCenterComponents.renderConstructionObjectSelector(cards, options)` возвращает HTML группы `role="tablist"`;
- `window.SCenterComponents.getConstructionObjectSelectorNextId(cards, activeId, key)` вычисляет следующий ID без побочных эффектов;
- `window.SCenterComponents.handleConstructionObjectSelectorKeydown(event, options)` обрабатывает `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, вызывает `options.onSelect(id, { focus: true, event })` и возвращает признак обработки.

`options` renderer содержит `activeId`, необязательные `ariaLabel`, `className` и `action`. Кнопки получают `data-construction-object-id`, `role="tab"`, `aria-selected` и roving `tabindex`.

## Визуальный контракт

Иконки типа объекта и отметка выбранной карточки рендерятся компонентом как встроенные SVG. Компонент не зависит от повторного вызова `lucide.createIcons()` после динамического показа feature, поэтому пиктограммы сохраняются при переключении между «Шахматкой» и «Объектами».

Стили изолированы префиксом `cos-`. На широком контейнере пять карточек делят ширину поровну. При ширине до `1180px` список получает локальную горизонтальную прокрутку и карточки шириной `220px`.

Компонент повторяет принятую стилистику карточек шахматки и делит каждую карточку на два смысловых блока. Верхний блок содержит иконку, название, description с параметрами объекта и check активной карточки; он отделен нижним border на всю ширину карточки. Нижний блок состоит из зоны готовности с круговым графиком и процентом и зоны пояснения к ходу работ; зона готовности отделена от пояснения вертикальным border, а пояснение выводится шрифтом `14px`. Нижняя отдельная meta-строка не выводится, чтобы параметры не дублировались. Длинные названия и подписи обрезаются многоточием и доступны через `title`.

## Границы ответственности

- компонент не меняет `window.activeContext`;
- компонент не синхронизирует выбор между features;
- компонент не хранит состояние и не навешивает глобальные listeners;
- focus после перерендера восстанавливает вызывающая feature по флагу `focus` из keyboard helper.
