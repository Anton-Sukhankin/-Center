# Справочные материалы

Документы в этой папке используются как контекст для анализа, обсуждений и ответов на вопросы пользователя.

Эти материалы не являются техническим заданием и не должны автоматически применяться к разработке, структуре проекта, данным или функциональности без отдельной прямой команды пользователя.
