# Исторические визуальные источники раздела «Шахматка»

Раздел `Шахматка` удален из активного прототипа после переноса в другой проект. Папка сохраняет принятые визуальные материалы как историю решения и не является источником текущего runtime-поведения.

Исключение — `object-cards-and-metrics.png`: он остается дополнительным визуальным источником активного раздела `Объекты` и связан с `docs/reference/objects/README.md`.

## Состав

- `source-reference.png` — исторический пользовательский референс задачи;
- `selected-direction.png` — историческое согласованное направление компоновки;
- `object-cards-and-metrics.png` — дополнительный источник действующего visual contract карточек раздела `Объекты`;
- `comparison-modal.png` — исторический источник удаленного сценария сравнения;
- `integrated-layout-reference.png` — исторический контрольный снимок компоновки до интеграции.

Эти материалы не разрешают повторную интеграцию удаленного раздела без отдельного решения. Промежуточные варианты, browser-аудиты, сборка Vite, зависимости и исходники бывшего стенда не сохранены.
