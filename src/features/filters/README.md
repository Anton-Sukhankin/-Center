# Фильтры событий

## Назначение

Feature `filters` отвечает за настройку выдачи событий внутри активного контекста.

## Код

- `filter-drawer.js`;
- `filter-drawer.css`.

## Источник данных

Фильтр берет данные из общего слоя:

- источники событий: `appData.getEventSources()`;
- дерево метрик: `appData.getMetricSelectorTree(window.metricsData)`;
- текущее состояние фильтра: `window.filterState`.

## Пользовательский путь

Пользователь открывает панель фильтра, выбирает источник, приоритет, период или метрику, применяет фильтр и видит обновленную ленту событий.

## Важные правила

Фильтрация применяется внутри активного контекста дерева. Выбор нового бизнес-юнита, проекта или очереди сбрасывает пользовательские фильтры.

Исключение событий из выдачи активно только при наличии примененных фильтров.

## Публичные интерфейсы

- `window.openFilterDrawer`;
- `window.closeFilterDrawer`;
- `window.applyFiltersAndSync`;
- `window.resetAllFilters`.

## Когда обновлять документ

Документ нужно обновлять, если меняется набор фильтров, источник значений, правила применения, связь с вкладками событий или поведение исключения событий.
