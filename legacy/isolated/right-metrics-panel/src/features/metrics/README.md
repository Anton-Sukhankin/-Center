# Структура метрик

## Назначение

Feature `metrics` отвечает за drawer структуры финансовых метрик и синхронизацию выбора метрики с правой панелью.

## Код

- `metric-drawer.js`;
- `metric-drawer.css`.

## Источник данных

Feature использует:

- `window.metricsData`;
- `window.activeMetricId`;
- `window.setActiveMetricId`;
- `window.openChartWidget`.

`window.metricsData` рассчитывается в `appData.getMetricsForContext(activeContext, events)`.

## Данные

Feature работает с расчетным деревом финансовых метрик: названием, фактом, планом, прогнозом, отклонением от бюджета, отклонением от предыдущего месяца, дочерними метриками и математическим признаком влияния на родителя.

## Пользовательский путь

Пользователь открывает структуру метрик, раскрывает дерево, выбирает метрику и видит синхронное обновление правой панели. Из структуры метрик пользователь может открыть BI-график.

## Важные правила

Drawer структуры метрик и правая панель должны использовать один и тот же источник `window.metricsData`.

Родительские метрики рассчитываются из дочерних с учетом математического признака: доходные и положительные показатели прибавляются, расходные, налоговые и отрицательные показатели вычитаются.

Базовые значения финансовой метрики — факт и план. Прогноз, отклонение от плана и отклонение от предыдущего месяца являются расчетными параметрами, которые помогают оценивать динамику и риск.

События не должны напрямую переписывать текущий финансовый факт. Они формируют прогнозируемое влияние через ИИ и ML-модели: сначала определяется нижняя релевантная метрика, затем оценивается влияние по дереву на верхнюю метрику, например на чистую прибыль.

Исключение события из выдачи не влияет на числовые значения финансовых или строительных метрик. Оно влияет только на текущую экранную выборку и на массив событий, который пользователь передает в массовый ИИ-анализ.

Атрибутные фильтры ленты событий также не меняют числовые значения метрик. Показатели обновляются при смене структурного контекста: бизнес-юнит агрегирует проекты, проект агрегирует очереди, очередь показывает собственные значения. Фильтрация карточек нужна для поиска, фокуса пользователя и подготовки массива для ИИ-анализа.

Корневая финансовая метрика — `Чистая прибыль`. Для руководителя проекта ключевой целевой метрикой считается `Валовая прибыль`.

Базовая декомпозиция финансового дерева:

```text
Чистая прибыль
  + Прибыль до налогообложения
    + Прочие доходы
    + Операционная прибыль
      + Валовая прибыль
        + Выручка
        - Себестоимость
      - Управленческие расходы
      - Коммерческие расходы
      - Прочие расходы
    - Финансовые расходы
  - Налог на прибыль
```

Строительные показатели не являются частью финансового дерева. Они отображаются отдельно и включают длительность проекта, объем проекта или работ и ТЭП, включая общепродаваемую площадь.

## Форматы отображения

| Формат | Назначение |
| --- | --- |
| Правая панель | Статичные цифровые карточки текущего месяца: строительные показатели, выбранная фокусная финансовая метрика и один уровень дочерних метрик. |
| Drawer структуры метрик | Полное навигационное дерево показателей с индикацией математического влияния дочерних метрик на родителя. |
| BI-график | Отдельная модалка для анализа динамики выбранной метрики на всем жизненном цикле проекта: история, бюджет и прогноз. |

## Строка дерева метрик

Строка в drawer структуры метрик отличается от строки левого структурного дерева. Она не выбирает проект или очередь, а помогает навигироваться по финансовой иерархии.

Обязательные параметры строки:

| Параметр | Назначение |
| --- | --- |
| Название показателя | Имя финансовой метрики, например `Чистая прибыль`, `Выручка` или `Налог на прибыль`. |
| Математический индикатор | Знак или иконка `+` / `-`, показывающая, прибавляется ли показатель к родителю или вычитается из него. |
| Уровень вложенности | Визуальный отступ и раскрытие дочерних метрик. |
| Состояние выбора | Синхронизирует выбранную метрику с правой панелью и BI-графиком. |

## Когда обновлять документ

Документ нужно обновлять, если меняется структура дерева, расчет метрик, синхронизация с правой панелью, открытие BI или правила выбора активной метрики.

## Ограничения прототипа и будущие требования

Сейчас структура метрик работает с демонстрационным расчетным деревом. В будущем нужно вынести арифметику дерева в отдельный источник, добавить реальные финансовые значения, ролевую видимость метрик и поддержку множественного влияния событий.
