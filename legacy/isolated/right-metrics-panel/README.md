# Изолированный модуль: правый блок метрик

## Статус

`isolated`.

Правый блок метрик удален из активного интерфейса прототипа S.Center и сохранен здесь как обратимо возвращаемый модуль.

## Почему изолирован

Принято решение убрать правую панель метрик из текущего интерфейса. При этом ее визуальные компоненты, drawer структуры метрик и BI-модалка могут понадобиться позже. До отдельной команды на возврат этот модуль не считается частью активной структуры проекта.

## Что входит

- `src/components/metric-card/` — карточки финансовых метрик правой панели.
- `src/components/construction-metric-card/` — карточки строительных показателей правой панели.
- `src/features/metrics/` — drawer структуры метрик.
- `src/features/bi/` — BI-модалка выбранной метрики.
- `src/styles/financial-analysis.css` — стили финансового блока.

## Что осталось в активном проекте

В активном проекте сохранены данные, заглушка дерева и отдельно восстановленный BI-сценарий:

- `window.metricsData`;
- `window.activeMetricId`;
- расчетные функции в `src/data/app-data.js`;
- `window.openTreeDrawer` как no-op/stub-контракт;
- активные `window.openBIModalV2`, `window.openChartWidget`, `window.onMetricClick` из `src/features/bi/` и `src/app/app.js`.

События, фильтры, ассистент и активный BI продолжают использовать связь события с метрикой даже без правого визуального блока. Файлы BI внутри этой архивной папки не подключаются; рабочая версия находится в `src/features/bi/`.

## Как вернуть модуль

Возврат запрещен без отдельной команды пользователя и отдельного плана.

Минимальная последовательность возврата:

1. Перенести файлы из этой папки обратно в соответствующие активные директории `src/`.
2. Вернуть CSS и JS подключения в `index.html`.
3. Вернуть разметку `<aside id="right-sidebar">`.
4. Заменить no-op/stub-контракты в `src/app/app.js` на активный рендер правой панели, drawer и BI.
5. Обновить документацию активных компонентов и матрицу соответствия.
6. Проверить `node --check`, локальные подключения и сценарии выбора контекста, событий, метрик, drawer и BI.

## Правило чтения

Не читать и не индексировать эту папку при обычной работе над прототипом. Использовать только по прямой команде пользователя на восстановление, аудит или интеграцию правого блока метрик.
