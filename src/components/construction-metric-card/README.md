# ConstructionMetricCard

## Назначение

`ConstructionMetricCard` отображает одну карточку строительного показателя в правой панели.

## Код

- `construction-metric-card.js`.

## Источник данных

Карточка получает готовые значения из `appData.getConstructionMetricsForContext(activeContext)`.

Базовая расчетная единица — очередь. Проект агрегирует очереди, бизнес-юнит агрегирует проекты.

## Отображаемые данные

Текущий интерфейс использует две карточки:

- длительность проекта;
- объем проекта.

Каждая карточка отображает план, прогноз и отклонение.

## Пользовательский путь

Пользователь выбирает бизнес-юнит, проект или очередь в левом дереве. После выбора значения строительных показателей в правой панели должны измениться.

## Зависимости

Компонент использует:

- `window.SCenterUI`;
- `window.SCenterComponents.renderConstructionMetricCard`;
- `src/app/app.js` для передачи расчетных значений.

## Когда обновлять документ

Документ нужно обновлять, если меняется список строительных показателей, правила агрегации, состав отображаемых значений, визуальная структура карточки или связь с активным контекстом.
