# Базовый UI-слой

Общие React-примитивы находятся в `react/ui/`. Они получают состояние через props и обслуживают несколько сценариев.

Внешние углы диалогов, включая боковые панели, подтверждения и окна HTML-полигона, используют общий радиус `--dialog-radius` (16 px) из базовых стилей. Он не распространяется на фон затемнения и вложенные элементы.

Между рамками соседних окон используется `--dialog-pair-gap` (24 px). Если окно перекрывает исходное на узком экране, правило зазора не применяется.

В экранной тёмной теме шапки таблиц используют `--table-head-fill`: поверхность сводных карточек (`--ui-summary-card-surface`) с примесью 7% белого. Цвет текста, высота шапок и печатные стили независимы от этой заливки.

| Примитив | Назначение |
| --- | --- |
| [Icon](../../react/ui/Icon.jsx) | Иконки Lucide из зафиксированной зависимости. Имена сценариев преобразуются в React-компоненты. |
| [LightlineButton](../../react/ui/LightlineButton.jsx) | Круглые кнопки 40 × 40 px со встроенными SVG. `FilterButton` отражает открытие фильтра событий и применение условий. `CloseButton` используется в шапках модальных окон и drawer и принимает обработчик закрытия от сценария. |
| [InlineText](../../react/ui/InlineText.jsx) | Вывод текста с переносами и выделением через React-узлы. |
| [useDialog](../../react/ui/useDialog.js) | Общий стек активных диалогов. Верхний уровень обрабатывает `Escape` и `Tab`, включая доступные связанные кнопки. Если несколько слоёв закрываются вместе, фокус возвращается к первому доступному источнику по цепочке открытия. |
| [refinements.css](../../react/ui/refinements.css) | Состояние фокуса, компактная раскладка тулбара и небольшие общие поправки UI. |

Стили предметных компонентов хранятся рядом с их паспортами. Изменения клавиатуры и слоев проверяются в затронутых пользовательских сценариях по [карте влияния](../../docs/component-impact-map.md).

[useAnimatedDialog](../../react/ui/useAnimatedDialog.js) дополняет существующий стек `useDialog`, не заменяя оболочки. При наличии видимого источника отдельная поверхность анимируется между его границами и окном; содержимое проявляется без изменения масштаба. Без источника окно проявляется и затухает на месте. Вход — 300 мс, выход — 214 мс; при уменьшенном движении — сразу. Затемнение и фокус сохраняют принадлежность к окну до завершения выхода. Подтверждение защиты от повторных действий происходит до запуска применения; отмена анимации или размонтирование очищает переход. Ассистент и нативный просмотр генплана сохраняют свои реализации.
