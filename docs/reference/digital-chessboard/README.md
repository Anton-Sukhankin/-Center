# Визуальные источники «Цифровой шахматки»

Папка хранит только канонические визуальные материалы, которые нужны для проверки активного feature после удаления экспериментального стенда. Источником истины для текущего поведения и структуры остается `src/features/digital-chessboard/README.md`, а для реализованного кода — `src/features/digital-chessboard/` и `src/data/digital-chessboard-data.js`.

## Состав

- `source-reference.png` — исходный пользовательский референс задачи;
- `selected-direction.png` — согласованное направление компоновки шахматки;
- `object-cards-and-metrics.png` — принятый визуальный контракт карточек объектов и панели метрик;
- `comparison-modal.png` — источник для сценария настройки сравнения;
- `integrated-layout-reference.png` — контрольный снимок итоговой компоновки до интеграции.

Промежуточные варианты, browser-аудиты, сборка Vite, зависимости и исходники бывшего стенда намеренно не сохранены: они не являются частью активной архитектуры.
