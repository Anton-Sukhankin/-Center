# MetricCard

## Назначение

`MetricCard` отображает финансовые показатели в правой панели: сводную карточку активной метрики и карточки дочерних метрик.

## Код

- `metric-card.js`.

## Компоненты

Файл предоставляет:

- `renderFinancialMetricSummaryCard`;
- `renderFinancialMetricChildCard`.

## Источник данных

Компонент получает расчетные финансовые метрики из `window.metricsData`.

Значения рассчитываются в `appData.getMetricsForContext(context, events)` на основании событий активного контекста.

## Пользовательский путь

Пользователь видит активную финансовую метрику, переходит к дочерним метрикам и открывает BI-график по выбранной метрике.

## Зависимости

Компонент использует:

- `window.SCenterUI`;
- `window.openChartWidget`;
- `window.setActiveMetricId`.

## Когда обновлять документ

Документ нужно обновлять, если меняется состав показателей, расчетные значения, способ перехода по дереву, связь с BI-графиком или визуальное поведение карточек.
