# Реестр доказательств приемки

Каталог хранит только принятые визуальные и аналитические материалы, которые подтверждают действующие интерфейсные или поведенческие контракты S.Center.

Правила хранения:

- у каждой группы материалов есть локальный `README.md` с областью проверки, результатом и перечнем файлов;
- raw-снимки, промежуточные варианты и воспроизводимые генерации после приемки не сохраняются;
- evidence не является источником требований: актуальные требования находятся в component/feature README и системных документах;
- при изменении подтверждаемого контракта evidence обновляется или помечается историческим.
