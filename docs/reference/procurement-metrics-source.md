# Эталонная транскрипция метрик закупок

## Статус документа

| Признак | Значение |
| --- | --- |
| Тип | справочный материал; эталонная транскрипция первоисточника |
| Авторитетность | эталонный для дословного содержимого зафиксированной версии Excel; ненормативный для UI, поведения и промышленной методики |
| Временной слой | снимок источника на момент проверки |
| Уровень | `MetricsDashboard → Закупки` |
| Жизненный статус | актуален для указанной контрольной суммы |
| Следующее действие | пересоздать транскрипцию и обновить контрольную сумму при замене Excel-первоисточника |

## Когда открывать

Использовать документ только когда нужно:

- проверить полноту состава закупочных метрик;
- дословно сопоставить название, описание, расчет, связь, приоритет или исходный формат;
- проверить расхождение между Excel, продуктовой сегментацией, demo-данными и интерфейсом;
- обновить документацию после получения новой версии первоисточника.

Не загружать документ для обычных правок отступов, типографики, сетки, адаптива, интеракций, оболочки `MetricsDashboard` или демонстрационных числовых значений. Для таких задач использовать [паспорт вкладки `Закупки`](../../src/features/metrics-dashboard/sections/procurement/README.md) и соответствующий runtime.

## Границы авторитетности

- Этот документ подтверждает только содержимое указанной версии Excel.
- Значения столбца `Расчет` являются текстовыми определениями из источника, а не формулами ячеек Excel и не подтвержденной промышленной методикой.
- В первоисточнике нет demo-сумм, норм, дат, TOP-3 позиций или строк закупок под риском, используемых активным прототипом.
- Сегментация по аналитическим блокам, адаптация формата и действующий UI-контракт принадлежат [паспорту вкладки `Закупки`](../../src/features/metrics-dashboard/sections/procurement/README.md).
- Фактические demo-значения активного интерфейса принадлежат [`procurement-metrics-data.js`](../../src/data/procurement-metrics-data.js) и описываются в [`src/data/README.md`](../../src/data/README.md).
- Будущие источники, владельцы, периодичность, качество данных и промышленная агрегация относятся к [плану интеграции реальных данных](../plans/metrics-real-data-integration-plan.md).

## Правило повторной проверки

Если Excel-файл получает другую контрольную сумму, эта транскрипция считается требующей проверки. Перед обновлением продуктового каталога или интерфейса необходимо повторно прочитать весь диапазон источника, сопоставить строки и только после этого обновить производные документы и runtime.
