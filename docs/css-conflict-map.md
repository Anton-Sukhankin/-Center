# Карта CSS-конфликтов карточки события

## Активный владелец

- Базовый внешний вид карточки события находится в `src/components/event-card/event-card.css`.
- Текущая активная разметка карточки создается в `src/app/app.js` и использует классы `event-card`, `event-card-top`, `event-source-icon`, `event-card-info`, `event-card-title`, `event-card-desc`, `selection-toggle-btn`, `ec-footer`.

## Файлы со связанными правилами

- `src/components/event-card/event-card.css`: основной владелец визуального состояния карточки, действий, footer влияния и выпадающего меню.
- `src/styles/event-list.css`: отвечает за сетку `.events-grid` и старые вспомогательные состояния списка. Базовый `.event-card` из него удален.
- `src/styles/global.css`: отвечает за общую компоновку приложения и больше не содержит активный блок внешнего вида карточки.

## Остаточные риски

- В `event-card.css` остаются совместимые правила для старой структуры `ec-header`, `ec-body`, `ec-title`; они не используются активной карточкой из `app.js`, но пока оставлены, чтобы не ломать возможные reference-сценарии.
- В `event-list.css` остаются правила для старых классов `card-header`, `card-title`, `exclude-btn`; они не используются текущей карточкой, но могут быть удалены отдельным этапом после визуальной проверки.
- При будущей чистке нужно проверять hover, excluded-состояние, footer влияния и кнопку скрытия карточки.
