# React-версия AIShtab

Заголовок каждого модального окна и диалоговой панели отмечается `data-dialog-title` и имеет размер 20 px и начертание Medium (500). Внутренние разделы сохраняют собственную типографику.

## Назначение

React — основной прототип AIShtab. В хедере находятся логотип и «AI ассистент». Тёмная тема — единственная: она применяется до загрузки React независимо от системной темы и прежнего выбора в браузере. [Палитра рабочего пространства](../src/styles/workspace-theme.css) применяется к документу, включая вложенные окна и графики; правила печати отделены от экранного оформления.

Основной шрифт интерфейса, включая ассистента, — установленный на устройстве CoFo Sans (Regular и Medium). Шрифтовые файлы не распространяются в сборке. Если локального начертания нет, используется Inter, затем системный шрифт. Размеры, межстрочные интервалы и запрошенная насыщенность компонентов не меняются; отдельные файлы SemiBold и Bold не подключены.

## Запуск

Использовать Node.js 22.19 или совместимую версию, поддерживаемую фиксированной версией Vite. Из корня выполнить `npm ci` и `npm run dev`. Адрес React-прототипа — `http://127.0.0.1:5173/`. Нативный прототип доступен по [инструкции восстановления из Git](../README.md#восстановление-нативной-версии).

`npm run build` собирает React в `dist/`. `npm run preview` отдает эту сборку на порту 4173. Тот же каталог указан в [конфигурации Sites](../.openai/hosting.json).

В [App](app/App.jsx) находятся текущий структурный контекст, активная поверхность, фильтры выдачи и состояние взаимосвязанных окон. Компоненты получают данные и обработчики через props. Локальные состояния, включая раскрытие строк, ввод формы и подсказку BI, принадлежат соответствующим компонентам. Общий [модальный стек](ui/useDialog.js) управляет клавиатурой и фокусом.

[Мост данных](app/data.js) подключает общие демонстрационные наборы `src/data`. Поля выбранной сущности, дерево финансовых метрик и дашборд рассчитываются по контексту. Выборка ленты поддерживает локальные изменения событий и не меняет исходные значения метрик при исключении карточек. Задачи хранятся в памяти страницы.

«Сводка», «Объекты» и ассистент загружаются по обращению. «Сводка» и «Объекты» сохраняют собственное состояние после первого открытия. Общие стили берутся из текущих компонентов. Иконки новой сборки поставляются с версионированной зависимостью.

## Микровзаимодействия в React-версии

- У карточек, обеих групп сегментов, дерева контекста и прямых переходов между экранами есть клавиатурный путь.
- При нехватке ширины тулбар переносит вторую группу и действия на следующую строку. Текстовый поиск событий не выводится.
- Закрытие BI по `Escape` возвращает в карточку или строку дерева. Подсказка и выделение месяца скрываются после ухода указателя и сбрасываются при смене прогноза или метрики.
- Открытие формы задачи переводит фокус в название. Поля проверяются до сохранения, обе точки выбора ответственного доступны с клавиатуры.
- Изменение приоритета обновляет вкладки и счетчики. Подтвержденное скрытие удаляет событие из текущей выдачи в памяти. Исключение из фильтрованной выборки восстанавливается при сбросе фильтров.
- В закупочной таблице сохраняются данные демонстрационной процедуры. Вкладки и финансовое дерево поддерживают клавиатурное переключение. «Сводка» и «Объекты» сохраняют предусмотренное состояние таблиц при возврате.
- Ожидание аналитики начинается сразу. Закрытие ассистента останавливает ожидающий demo-ответ и возвращает фокус к кнопке.

## Проверки

Сборка — `npm run build`. Ссылки и владельцы — `node scripts/check-documentation.mjs`. [Браузерная регрессия](../scripts/check-react-browser.mjs) выполняется командой `node scripts/check-react-browser.mjs` при доступном Playwright и запущенном сервере. Для внешней установки Playwright можно указать модуль через `AISHTAB_PLAYWRIGHT_MODULE`. `AISHTAB_REACT_URL` выбирает адрес проверки; `AISHTAB_BUILD_ROOT` позволяет прогнать локальную Vite-сборку в Chromium без запуска сервера. `AISHTAB_BASELINE_URL` включает сравнение первой карточки и счётчиков с нативной версией. Расширенный перечень сценариев сохранён в [архиве приёмки](../docs/archive/plans/aishtab-react-acceptance-cutover-plan.md).
