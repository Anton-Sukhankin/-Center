# Матрица соответствия системы S.Center

## Назначение

Матрица показывает, насколько активные области прототипа соответствуют продуктовой модели по четырем независимым измерениям. Она не дублирует локальные визуальные и runtime-контракты: их владельцами остаются component/feature README и evidence.

Обозначения: `да` — контракт текущего прототипа выполнен; `частично` — demo-сценарий работает, но промышленная модель неполна; `нет` — требование отсутствует в активной реализации; `н/п` — измерение неприменимо.

## Правило обновления

При изменении назначения, данных, интеграции, visual QA или пользовательского пути обновляются строка матрицы и локальный паспорт. Будущие требования фиксируются в `docs/plans/system-scaling-roadmap.md`, а завершенная история — в `docs/archive/plans/`.
