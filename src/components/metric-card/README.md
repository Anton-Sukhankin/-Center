# MetricCard

## Назначение

`MetricCard` отображает финансовые показатели в правой панели: сводную карточку активной метрики и карточки дочерних метрик.

## Код

- `metric-card.js`.

## Компоненты

Файл предоставляет:

- `renderFinancialMetricSummaryCard`;
- `renderFinancialMetricChildCard`.

## Источник данных

Компонент получает расчетные финансовые метрики из `window.metricsData`.

Значения относятся к активному структурному контексту: бизнес-юниту, проекту или очереди. Атрибутные фильтры ленты событий, закрепление и исключение карточек не должны менять числовые значения в `MetricCard`.

## Данные

Компонент отображает название метрики, факт, план, прогноз, отклонение от бюджета, отклонение от предыдущего месяца и связь с дочерними метриками. Все значения приходят из расчетного дерева `window.metricsData`.

## Отображаемые параметры

Карточка финансовой метрики в правой панели является статичным цифровым срезом текущего отчетного месяца. Она не показывает длинный график жизненного цикла проекта; график открывается отдельно через BI.

Обязательные параметры:

| Параметр | Назначение |
| --- | --- |
| Название метрики | Отображаемое имя показателя, например `Чистая прибыль`, `Валовая прибыль` или `Выручка`. |
| Фактическое значение | Актуальная цифра на текущий отчетный месяц. |
| Плановое значение | Бюджетное значение, заложенное в финансовую модель. |
| Прогнозное значение | Ожидаемое финальное значение на момент окончания проекта. |
| Отклонение | Дельта между фактом и бюджетом, а также динамика относительно предыдущего месяца. |
| Визуальная индикация | Иконка, цвет, знак или другое компактное обозначение, помогающее быстро считать тип и динамику показателя. |

## Пользовательский путь

Пользователь видит активную финансовую метрику, переходит к дочерним метрикам и открывает BI-график по выбранной метрике.

## Зависимости

Компонент использует:

- `window.SCenterUI`;
- `window.openChartWidget`;
- `window.setActiveMetricId`.

## Когда обновлять документ

Документ нужно обновлять, если меняется состав показателей, расчетные значения, способ перехода по дереву, связь с BI-графиком или визуальное поведение карточек.
