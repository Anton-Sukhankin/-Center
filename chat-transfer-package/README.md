# Автономный пакет ИИ-чата S.Cost

Папка переносится в другой проект целиком. Исходные файлы интерфейса находятся в `src/`, а вся связь с конкретным приложением должна оставаться в отдельном адаптере.

## Состав

- `src/AIChat.js` — разметка, состояние, список чатов, сообщения и публичный API.
- `src/AIChat.css` — стили и дизайн-токены компонента.
- `src/demo-provider.js` — демонстрационные ответы; в продукте заменяется реальным API.
- `adapters/scost-prototype-adapter.*` — пример связи с исходным проектом.
- `demo/` — автономный запуск без исходного приложения.
- `docs/` — контракт интеграции и визуальные состояния.
- `tests/interaction-checklist.md` — приёмочные сценарии.

## Главное правило переноса

Не переписывайте `src/AIChat.js` и `src/AIChat.css` под целевой проект. Создайте новый адаптер, реализующий контекст, провайдер сообщений, хранилище, вложения и действия приложения.

Начните с [документа интеграции](docs/integration.md), затем пройдите [чек-лист](tests/interaction-checklist.md).
