# Визуальные темы источников событий

## Назначение

Документ фиксирует правило цветовой индикации продуктов и систем, которые отображаются в верхней строке карточки события центральной ленты.

Источник события является частью данных события. Поэтому цвет тега продукта, цвет подложки иконки, цвет иконки и цвет текста должны храниться в справочнике источников, а не задаваться отдельными CSS-исключениями для каждой карточки.

## Где хранится правило

- Данные источников: `src/data/app-data.js`, массив `eventSources`.
- Компонент карточки: `src/components/event-card/event-card.js`.
- Визуальный слой карточки: `src/components/event-card/event-card.css`.

## Атрибуты темы источника

Каждый источник может иметь объект `theme`:

| Атрибут | Назначение |
| --- | --- |
| `chipBg` | Начальный цвет фона тега продукта. |
| `chipBgEnd` | Конечный цвет фона тега продукта. |
| `iconBg` | Цвет круглой подложки иконки продукта. |
| `iconColor` | Цвет самой иконки продукта. |
| `textColor` | Цвет наименования продукта внутри тега. |

## Текущие темы

| Источник | Тема |
| --- | --- |
| `S.Pass` | Голубой тег, синяя подложка иконки. |
| `S.Center` | Индиго-тег, индиго-подложка иконки. |
| `S.Control` | Зеленый тег, зеленая подложка иконки. |
| `MS Project` | Фиолетовый тег, фиолетовая подложка иконки. |
| `S.Materis` | Оранжевый тег, оранжевая подложка иконки. |

## Правило отображения

`event-card.js` получает тему из view model события и передает ее в `product-chip` через CSS-переменные:

- `--source-chip-bg`;
- `--source-chip-bg-end`;
- `--source-icon-bg`;
- `--source-icon-color`;
- `--source-text-color`.

`event-card.css` использует эти переменные с fallback-значениями. Если у нового источника тема еще не задана, карточка сохранит базовую голубую тему.

## Когда обновлять документ

Документ нужно обновлять, если:

- добавлен новый продукт или источник события;
- изменились цвета существующего продукта;
- изменился набор атрибутов `theme`;
- product-chip начал использовать другую структуру разметки или другой способ передачи цветов.
