# Завершенный план: удаление переданной переносимой копии шахматки

Статус: завершен 24.08.2026. План подчиняется регламенту `../../plans/README.md` и сохраняется только как история выполненного удаления.

## Goal

Удалить из корня AIShtab папку `digital-chessboard-transfer/` после подтвержденного пользователем копирования в другой проект и очистить актуальную документацию от ссылок на локальный пакет.

## Scope

- удалить только `digital-chessboard-transfer/`;
- убрать пакет из текущих карт, compliance, корневой навигации и feature README;
- сохранить архивную историю формирования и передачи пакета.

## Out of Scope

- активный `src/features/digital-chessboard/`;
- dropdown и header-entry `Цифровая шахматка`;
- shared selector и data-файлы активного прототипа;
- проект, в который пользователь скопировал пакет.

## Constraints

Цель удаления должна быть прямым дочерним каталогом корня проекта. Активный runtime и публичные `window.*` не изменяются.

## Impact

Меняется только структура корня и документационная топология переносимого снимка. Пользовательский путь активной шахматки не меняется.

## Steps

1. Проверить абсолютный путь и состав удаляемого каталога.
2. Удалить каталог по точному пути.
3. Удалить актуальные ссылки и обновить архивный результат.
4. Проверить документацию, отсутствие оставшихся runtime-ссылок и активную шахматку.

## Acceptance Criteria

- `digital-chessboard-transfer/` отсутствует в корне;
- активная шахматка открывается и работает как прежде;
- актуальные документы не ссылаются на удаленные файлы;
- архив явно фиксирует передачу и последующее удаление локальной копии.

## Documentation Updates

- `README.md`;
- `docs/README.md`;
- `docs/component-map.md`;
- `docs/component-impact-map.md`;
- `docs/system-compliance-matrix.md`;
- `src/features/digital-chessboard/README.md`;
- `docs/archive/plans/digital-chessboard-transfer-package-plan.md`;
- после приемки — `docs/archive/plans/README.md`.

## Verification

- `rg` по имени удаленного каталога вне архивных планов;
- `node scripts/check-documentation.mjs`;
- browser smoke-check активного раздела `Шахматка`.

## Result

Подтвержденная пользователем переданная копия `digital-chessboard-transfer/` удалена из корня AIShtab. Актуальные карты и README очищены от ссылок на пакет. Активная шахматка, ее header-entry, данные и shared-компоненты не изменялись.
