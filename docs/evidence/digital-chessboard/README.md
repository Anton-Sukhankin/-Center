## Результат

Интегрированная шахматка сохраняет согласованные структуру карточек объектов, сводную строку, рабочую карточку, таблицу, статусные цвета, sticky-области и сценарии выбора/сравнения работ. Переходы между dashboard и шахматкой работают без reload и сохраняют состояние экранов.

Допустимые отличия относятся к общей оболочке S.Center, canonical demo-данным и адаптивной ширине контента.
