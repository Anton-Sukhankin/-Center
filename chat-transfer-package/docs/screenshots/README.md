1. `01-open-filled-1440x900.png`
2. `02-open-empty-1440x900.png`
3. `03-chat-list-collapsed.png`
4. `04-create-dialog.png`
5. `05-edit-dialog.png`
6. `06-delete-dialog.png`
7. `07-typing-indicator.png`
8. `08-min-width.png`

В этой среде новые снимки локальной страницы нельзя получить автоматически: встроенный браузер блокирует доступ к локальным файлам и локальному серверу. Папка и матрица состояний подготовлены; снимки следует сделать из `demo/index.html` или исходного приложения при доступном preview URL.
