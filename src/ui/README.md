# Базовый UI-слой

## Назначение

`src/ui/` содержит нейтральные UI-хелперы. Этот слой не должен знать про события, метрики, проекты или очереди.

## Файл

| Файл | Назначение |
| --- | --- |
| `ui-core.js` | Общие функции экранирования текста, атрибутов и вывода иконок. |

## Публичный интерфейс

Компоненты используют `window.SCenterUI`.

## Роль в системе

UI-слой помогает компонентам безопасно формировать HTML-строки и не дублировать базовые операции.

## Когда обновлять документ

Документ нужно обновлять, если:

- добавлены новые UI-хелперы;
- изменилось имя публичного объекта;
- изменились правила экранирования или вывода иконок;
- компонент начал зависеть от нового общего helper.
