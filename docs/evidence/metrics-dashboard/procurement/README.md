# Evidence: вкладка «Закупки»

Материалы фиксируют визуальную проверку нативной реализации вкладки `Метрики → Закупки` относительно выбранного MagicPath-компонента `438748094553792512`, ревизия `438748094553792513`.

## Состав

- `magicpath-source.png` — исходный browser-capture MagicPath;
- `prototype-implementation.png` — browser-capture активного нативного прототипа;
- `magicpath-source-normalized.png` — первый видимый кадр источника после нормализации масштаба;
- `prototype-implementation-normalized.png` — первый видимый кадр реализации после нормализации масштаба;
- `comparison.png` — полное сопоставление нормализованных кадров;
- `comparison-focused.png` — увеличенное сопоставление контрактации и финансового эффекта.

Встроенный браузер вернул изображения с повторяющимися кадрами при разных коэффициентах desktop-capture. Нормализованные файлы выделяют первый кадр с одинаковым соотношением сторон; они не являются самостоятельным продуктовым макетом.

Актуальный вывод и сценарии проверки находятся в [`design-qa.md`](../../../../design-qa.md). Текущее поведение вкладки описывает [`src/features/metrics-dashboard/sections/procurement/README.md`](../../../../src/features/metrics-dashboard/sections/procurement/README.md).
