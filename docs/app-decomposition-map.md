# Карта декомпозиции приложения AIShtab

Текущая реализация — React-сборка с корневым [index.html](../index.html). Нативный прототип сохранен под Git-меткой `aishtab-native-final`. Инструкция восстановления находится в [README](../README.md#восстановление-нативной-версии).

| Граница | Владелец |
| --- | --- |
| Подключение и стили | [main.jsx](../react/main.jsx) монтирует приложение и подключает общий CSS. |
| Контекст и маршрутизация слоев | [App](../react/app/App.jsx) хранит активный структурный узел, экран, параметры выдачи и связанные окна. |
| Данные и селекторы | [data.js](../react/app/data.js) предоставляет общие источники из `src/data/`. [feedModel](../react/events/feedModel.js) вычисляет локальную выдачу и счетчики. |
| UI и сценарии | Компоненты принимают данные и обработчики через props. Список входов приведен в [паспорте React-прототипа](../react/README.md#области-и-владельцы). |
| Локальное состояние | Ветки, формы, таблицы, прогноз, подсказки и чат хранятся у компонентов-владельцев. [Стек диалогов](../react/ui/useDialog.js) координирует фокус. |

При изменении общей границы сверять [слой приложения](../src/app/README.md) и [карту влияния](component-impact-map.md).
