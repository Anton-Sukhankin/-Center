# План: интеграция вкладки метрик «Закупки»

Статус: завершен 14.08.2026. План подчиняется правилам `docs/plans/README.md` и хранится как история выполненной интеграции.

## Goal

Добавить в действующий нативный прототип вкладку `Закупки` раздела `Метрики` и перенести в нее согласованный дизайн MagicPath со всеми демонстрационными данными и локальными интеракциями.

## Выполненный объем

- `Закупки` размещены сразу после `Общие` в единой оболочке `MetricsDashboard`;
- добавлен внутренний demo-provider на основании 19 метрик исходного файла;
- реализованы сводка, контрактация, финансовый эффект, эффективность процесса, таблица риска, фильтры и drawer;
- сохранены нативные HTML, CSS и JavaScript без React, ES-модулей, новых зависимостей и новых публичных `window.*`;
- синхронизированы паспорта, карты связности, матрица соответствия и визуальные evidence.

## Вне выполненного этапа

- реальные закупочные источники, backend-пересчет и persistence;
- утверждение норм и порогов;
- роли, права, BU-агрегация и переход к промышленной карточке тендера.

Эти пункты остаются в `docs/plans/metrics-real-data-integration-plan.md`.

## Проверка

- синтаксис измененных JavaScript-файлов;
- подключения CSS и JS из `index.html`;
- переключение вкладок, фильтры, сброс, mouse/keyboard drawer flow и возврат фокуса;
- визуальное сравнение с выбранной ревизией MagicPath;
- документационный checker.
