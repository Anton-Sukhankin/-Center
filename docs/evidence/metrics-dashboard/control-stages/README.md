# Аудит блока контрольных этапов

## Область проверки

Раздел `Метрики` → `Общие`, проект `Nova`, блок временной шкалы проекта.

## Цель пользователя

Быстро понять, какие этапы завершены, какой этап является текущим и какие этапы запланированы дальше.

## Шаги и результат

1. Открыт проект `Nova` и активирован сегмент `Метрики`. Состояние экрана работоспособно.
2. Проверен блок временной шкалы. Термин `веха` создавал несогласованность с принятой продуктовой терминологией `этап`.
3. Заголовок изменён на `Контрольные этапы`, подзаголовок — на `Текущий статус и ближайшие этапы проекта`, действие — на `Все этапы`.
4. Статусы приведены к согласованным формам `Завершён`, `Текущий этап`, `Запланирован`; заголовок получил `font-weight: 500`.
5. Проверено раскрытие шкалы: компактное состояние показывает 5 этапов, раскрытое — 9 этапов; `aria-expanded` меняется корректно. Итоговое состояние работоспособно.
6. Внутренний отступ карточки контрольных этапов унифицирован до `20px`; обе секции KPI- и бюджетных карточек используют тот же базовый отступ.

## Итог

Терминология блока стала последовательной и однозначной. Видимый текст ассистента, связанный с календарным контекстом, также использует термин `контрольные этапы`. P0/P1/P2-проблем по результатам проверки не обнаружено.

## Ограничения проверки

Встроенный браузер сохранил снимки плитками. Поэтому текст, количество элементов, состояние раскрытия и `font-weight` дополнительно подтверждены через DOM и вычисленные стили; полная проверка клавиатурного фокуса и контраста этим проходом не выполнялась.
