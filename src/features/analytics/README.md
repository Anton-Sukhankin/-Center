# AI-аналитика

## Назначение

Feature `analytics` отвечает за AI-модалку и сценарий аналитики по текущему состоянию интерфейса.

## Код

- `ai-insights.js`;
- `ai-insights.css`.

## Данные и зависимости

Feature использует:

- `window.aiInsights`;
- `window.triggerAIAnalysis`;
- состояние ленты событий;
- публичные функции приложения для открытия и закрытия связанных модальных окон.

## Пользовательский путь

Пользователь нажимает кнопку аналитики в тулбаре событий и получает модальное представление с аналитическими выводами по текущему контексту.

## Когда обновлять документ

Документ нужно обновлять, если меняется способ запуска аналитики, состав анализируемых данных, структура модального окна или связь с событиями и фильтрами.
