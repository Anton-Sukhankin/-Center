# Протокол визуальной сверки HTML-полигона закупок

Подчиняется `docs/plans/README.md`. Область: только локальный `procurement-lab.html`, не активная React-вкладка. Эталон композиции — выбранное изображение 1487 × 1058; источник значений, статусов и наименований — проектный демонстрационный набор. Из картинки нельзя переносить вымышленные суммы, предметы закупок и нормы.

| Порядок приёмки / владелец | Исходный кроп (x, y, ширина, высота) | Задача и проверяемые критерии |
| --- | --- | --- |
| 0. Оболочка — shell | 0, 0, 1487, 120 | Светлая шапка с названием проекта; крупный заголовок, поля около 16 px, две равные верхние панели с зазором 12–16 px; отметка о демоданных остаётся. |
| 1. Контрактация — budget | 15, 119, 727, 348 | Крупная сумма с единицей, под ней пояснение, насыщенная составная шкала с процентами внутри, компактная легенда, таблица направлений с общей строкой. Проверить доли и суммы источника. |
| 2. Превышение — overrun | 753, 119, 720, 348 | Красная сумма и процент на светлой подложке; переключатель справа; три компактные строки, общая шкала, видимые бюджет и договор. Оба сегмента и раскрытие исходных сумм работают. |
| 3. Риски — risk | 15, 482, 1458, 298 | Синий номер тендера, предмет отдельной колонкой, компактные строки, подписанные цветные статусы. Сохранить семь процедур, сумму стоимости, даты, подписанный запас и открытие деталей с возвратом фокуса. |
| 4. Эффективность — process | 15, 797, 1458, 232 | Единая компактная таблица из четырёх показателей; светлая строка заголовков, выровненные числа, акцент на разнице с нормой. Смысл оценки, единицы измерения и все значения источника сохранены. |

Ведущий сравнивает каждый блок отдельно в указанном порядке: эталон → исходный рендер → исправленный рендер. Затем проверяет общий кадр и раскладку на узком экране, переключение работ и материалов, детали источников, открытие и закрытие процедуры с клавиатуры. Расхождения фиксируются как исправления либо осознанные отличия ради данных, механики и доступности.

## Результат поочерёдной приёмки

Слева на каждой паре — соответствующий кроп выбранного изображения, справа — результат в браузере. Отчёт касается только HTML-полигона.

| Проверенный блок | Вердикт и основание |
| --- | --- |
| [Оболочка](../../evidence/metrics-dashboard/procurement-lab/final-shell.jpg) | Принято: шапка высотой 46 px, карточки начинаются на y=119, горизонтальные поля 16 px. Метка демонстрационных данных сохранена. |
| [Контрактация](../../evidence/metrics-dashboard/procurement-lab/final-budget.jpg) | Принято: 38-пиксельная шкала, три подписанных сегмента и три строки таблицы, включая итог 24,0 / 17,3 млрд ₽. Ширины частей соответствуют числам источника, а не приблизительной растровой геометрии. |
| [Превышение](../../evidence/metrics-dashboard/procurement-lab/final-overrun.jpg) | Принято: общая шкала, три строки с суммами, выделенный процент, переключатель на уровне суммы. Проверено переключение обеих категорий при открытой таблице исходных значений; уточнение «в млн ₽» не позволяет спутать её с колонкой в млрд ₽. |
| [Риски](../../evidence/metrics-dashboard/procurement-lab/final-risk.jpg) | Принято: панель высотой 295 px, семь строк, номера и цветные статусы. Обе исходные даты и сумма 163,2 млн ₽ не удалены ради изображения. Каждая из семи процедур открылась через Enter; Escape вернул фокус её кнопке. |
| [Эффективность](../../evidence/metrics-dashboard/procurement-lab/final-process.jpg) | Принято: начало на y=797, факт и норма выровнены, дельта выделена, оценка остаётся текстом. Четыре исходных показателя; пятую строку генерации не переносили. |

Проверена узкая раскладка вплоть до 320 CSS px с открытой таблицей точных сумм, без горизонтального переполнения страницы. Результат относится к браузеру Кодекса; другие браузеры и реальные интеграции не проверялись. [Общий кадр](../../evidence/metrics-dashboard/procurement-lab/final-full.jpg).
