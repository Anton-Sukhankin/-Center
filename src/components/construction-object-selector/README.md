# Компонент `construction-object-selector`

## Назначение

Компонент отображает повторяемую группу карточек выбора объекта строительства для раздела `Объекты`. Он не хранит выбранный объект и не объединяет feature-specific данные с общей identity объектов.

Селектор — общий React-компонент для «Объектов» и «Сводки».

## Реализация и стили

[ConstructionObjectSelector](../../../react/construction/ConstructionObjectSelector.jsx) и `construction-object-selector.css`.

## View model карточки

`renderConstructionObjectSelector(cards, options)` принимает массив:

| Поле | Назначение |
| --- | --- |
| `id` | Стабильный идентификатор объекта. |
| `name` | Название объекта. |
| `typeLabel` | Пользовательское название типа. Используется как fallback, если нет параметров для description. |
| `descriptionLabel` | Верхний description под названием объекта. Раздел `Объекты` передает сюда параметры объекта, ранее показанные в нижней meta-строке карточки. |
| `icon` | Имя иконки Lucide. |
| `progressPercent` | Готовность карточки в диапазоне `0–100`. |
| `deviationLabel` | Feature-specific подпись отклонения. |
| `deviationTone` | `behind` или `on-plan`. |
| `metaLabel` | Feature-specific структурная подпись и fallback для `descriptionLabel`. |

Stable identity должна поступать из `window.constructionObjectsData`; готовность, отклонение и структурная подпись остаются частью адаптера конкретной feature.

## Публичный API

`ConstructionObjectSelector` получает карточки, выбранный идентификатор и обработчик `onSelect`. Компонент связывает вкладки с панелью и обрабатывает стрелки, `Home` и `End`.

## Визуальный контракт

Иконки типа объекта и отметка выбранной карточки рендерятся компонентом как встроенные SVG. Компонент не зависит от повторного вызова `lucide.createIcons()` после динамического показа feature.

Стили изолированы префиксом `cos-`. На широком контейнере пять карточек делят ширину поровну. При ширине до `1180px` список получает локальную горизонтальную прокрутку и карточки шириной `220px`.

Компонент использует принятый визуальный контракт карточек строительных объектов и делит каждую карточку на два смысловых блока. Верхний блок содержит иконку, название, description с параметрами объекта и check активной карточки; он отделен нижним border на всю ширину карточки. Нижний блок состоит из зоны готовности с круговым графиком и процентом и зоны пояснения к ходу работ; зона готовности отделена от пояснения вертикальным border, а пояснение выводится шрифтом `14px`. Нижняя отдельная meta-строка не выводится, чтобы параметры не дублировались. Длинные названия и подписи обрезаются многоточием и доступны через `title`.

## Границы ответственности

- компонент не меняет структурный контекст;
- компонент не синхронизирует выбор между features;
- компонент не хранит состояние и не навешивает глобальные listeners;
- focus после перерендера восстанавливает вызывающая feature по флагу `focus` из keyboard helper.

## Acceptance

- `node --test src/components/construction-object-selector/construction-object-selector.test.mjs` проходит;
- пять карточек выбираются мышью и клавишами стрелок, `Home`, `End`;
- `aria-selected` и roving `tabindex` соответствуют активной карточке;
- description и fallback не дублируют нижнюю meta-строку;
- при ширине до `1180px` scroll остается локальным, без page-level overflow;
- повторный hide/show раздела `Объекты` сохраняет его локальный выбор до смены контекста.

## Когда обновлять документ

README обновляется при изменении view model, renderer, keyboard helper, visual contract или границы между общей identity объекта и feature-specific данными. Изменение общего контракта требует регрессии раздела `Объекты`.
