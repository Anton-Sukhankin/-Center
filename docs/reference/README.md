# Справочные материалы

Документы в этой папке используются как контекст для анализа, обсуждений и ответов на вопросы пользователя.

Эти материалы не являются техническим заданием и не должны автоматически применяться к разработке, структуре проекта, данным или функциональности без отдельной прямой команды пользователя.

## Маршрутизация

| Если нужно | Открыть | Не открывать автоматически |
| --- | --- | --- |
| Дословно сверить закупочные метрики с Excel-первоисточником | [`procurement-metrics-source.md`](procurement-metrics-source.md) | Для обычных UI-правок, работы с demo-значениями или оболочкой `MetricsDashboard` |
| Анализировать визуальный референс существующего раздела | локальный reference-подраздел затронутого feature | Если задача относится только к данным, поведению или документации компонента |

Эталонная транскрипция подтверждает содержимое конкретной версии источника, но не заменяет feature-паспорт, data-контракт или промышленную методику.
