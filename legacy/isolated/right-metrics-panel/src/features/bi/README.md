# BI-модалка

## Назначение

Feature `bi` отвечает за расширенное аналитическое представление выбранной финансовой метрики.

## Код

- `bi-modal-v2.js`;
- `bi-modal-v2.css`.

## Источник данных

BI-модалка открывается для выбранной финансовой метрики из `window.metricsData`.

Открытие вызывается из правой панели метрик или drawer структуры метрик.

## Данные

Feature использует выбранную метрику, ее расчетные значения и демонстрационный набор точек для графика. В целевой модели BI должен получать историю, бюджетную линию и прогноз на весь жизненный цикл проекта.

## Зависимости

- `window.metricsData`;
- `window.openBIModalV2`;
- `window.closeBIModal`;
- Chart.js.

## Пользовательский путь

Пользователь выбирает метрику и открывает график. Модалка показывает расширенную аналитику по этой метрике и должна сохранять связь с текущим активным контекстом.

## Публичные интерфейсы

- `window.openBIModalV2`;
- `window.closeBIModal`.

## Когда обновлять документ

Документ нужно обновлять, если меняется состав данных BI, способ открытия, связь с метриками, таблица, график или режим отображения рядом с drawer.

## Ограничения прототипа и будущие требования

Сейчас BI использует демонстрационные данные выбранной метрики. В будущем feature должен получать реальные исторические значения, бюджетную линию, прогноз и период жизненного цикла проекта из отдельного источника данных.

## Связь с матрицей соответствия

Feature отражен в `docs/system-compliance-matrix.md`. При изменении кода логики, визуального слоя, источника данных, состояний или пользовательского пути нужно обновить этот README, `docs/component-map.md` и матрицу соответствия.
