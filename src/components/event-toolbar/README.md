# EventToolbar

## Назначение

`EventToolbar` управляет верхней панелью ленты событий: вкладками, поиском, открытием фильтра и запуском аналитики.

## Код

- `event-toolbar.js`;
- `event-toolbar.css`.

## Состояния

Компонент поддерживает два режима:

- `default` — обычная лента событий;
- `filtered` — применены фильтры и показано количество найденных событий.

## Данные и зависимости

Компонент использует:

- `window.filterState`;
- `window.toolbarState`;
- `window.renderEventFeed`;
- `window.openFilterDrawer`;
- `window.triggerAIAnalysis`.

## Пользовательский путь

Пользователь переключает вкладки `Сегодня`, `Все события`, `Закрепленные`, вводит поисковый запрос, открывает фильтр или запускает аналитику.

## Когда обновлять документ

Документ нужно обновлять, если меняются вкладки, режимы тулбара, счетчики, поиск, кнопки действий или связь тулбара с фильтрами и аналитикой.
