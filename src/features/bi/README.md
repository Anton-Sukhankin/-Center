# BI-график метрики

## Назначение

Feature восстанавливает узкий пользовательский сценарий просмотра динамики связанной метрики из детальной карточки события. Он является активной частью прототипа, но не возвращает правую панель метрик или drawer древовидной структуры метрик.

## Код

- `bi-modal.js` — открытие, закрытие, демонстрационная временная серия, SVG-график, прогноз и hover-состояния;
- `bi-modal.css` — полноэкранное и side-by-side представление BI-модалки; overlay использует слой `2403`, чтобы график открывался выше overlay и панели детальной карточки события.

## Источник данных

Выбранная метрика передается из `window.metricsData` через `window.openChartWidget(metricId)`. Название, `fact`, `plan` и `forecast` берутся из текущего расчетного дерева активного контекста. Помесячная история пока генерируется детерминированно для прототипа и не считается промышленными данными.

## Пользовательский путь текущей реализации

1. Пользователь открывает детальную карточку события.
2. Нажимает карточку `Влияние на метрику`.
3. `window.onMetricClick` находит метрику по `metricId` в `window.metricsData` и открывает BI-модалку.
4. Пользователь может включить `Прогноз`, изучить значения по месяцам и закрыть график кнопкой, затемнением или `Escape`.
5. Drawer события остается открытым и сохраняет состояние.

На широком экране график располагается слева от открытого drawer. На более узком экране используется обычная полноэкранная модальная подложка. В обоих состояниях BI находится выше event drawer overlay, поэтому график не скрывается под затемнением детальной карточки. При закрытии side-by-side BI класс `is-side-by-side` удерживается до завершения fade-out, чтобы overlay не превращался на мгновение в полноэкранное затемнение поверх drawer.

Если пользователь закрывает детальную карточку события при открытом BI-графике, `src/app/app.js` сначала вызывает `window.closeBIModal({ skipFocusRestore: true })`, затем закрывает drawer. Это предотвращает сохранение графика без родительского контекста и не возвращает фокус в закрываемую карточку события.

## Пространственный контракт

- BI использует viewport overlay со слоем `2403` и открывается выше event drawer overlay.
- На широком viewport применяется `side-by-side` слева от drawer; на ограниченной ширине — полноэкранная modal.
- Закрытие по кнопке, overlay или `Escape` сохраняет event drawer и возвращает focus к карточке связанной метрики.
- Закрытие родительского event drawer сначала закрывает BI без возврата focus в исчезающий элемент.
- Класс `is-side-by-side` сохраняется до завершения fade-out, исключая промежуточное полноэкранное затемнение.

## Публичные интерфейсы

- `window.openBIModalV2(metric, sideBySide)`;
- `window.closeBIModal()`;
- `window.SCenterBI.open(metric, sideBySide)`;
- `window.SCenterBI.close()`;
- `window.SCenterBI.isOpen()`;
- `window.SCenterBI.getActiveMetric()`.

Интеграционные мосты `window.openChartWidget` и `window.onMetricClick` находятся в `src/app/app.js`. `window.openTreeDrawer` остается заглушкой.

## Состояния

- закрыто;
- открыто без прогнозных месяцев;
- открыто с прогнозом;
- hover выбранного месяца;
- side-by-side рядом с event drawer;
- полноэкранная модалка на ограниченной ширине.

## Ограничения и будущая модель

Историческая серия демонстрационная. Реальные месячные значения, единицы измерения, жизненный цикл проекта и методика прогноза должны подключаться отдельным этапом данных. Возврат BI не означает возврат правой панели или дерева метрик.

## Когда обновлять документ

Документ нужно обновлять при изменении источника истории, состава графика, прогноза, точек входа, модальных состояний или публичных интерфейсов BI.

## Acceptance

- из Event открывается метрика с совпадающим `metricId`;
- forecast переключается без изменения исходного дерева метрик;
- button/overlay/`Escape` закрывают BI и сохраняют event drawer;
- side-by-side и полноэкранный режимы не перекрывают критичные контролы;
- закрытие Event не оставляет BI без родительского контекста;
- focus возвращается только в существующий trigger.

Автоматического локального `*.test.mjs` для BI сейчас нет.
