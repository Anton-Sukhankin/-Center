# Аудит внутренних вкладок раздела «Метрики»

## Область проверки

Верхняя часть центральной области S.Center: `EventToolbar`, вкладки приоритета в режиме `Сегодня` и внутренние вкладки дашборда в режиме `Метрики`.

## Цель пользователя

Считать внутренние вкладки метрик как прямое продолжение верхней панели и быстро понимать активный подраздел без смены визуального языка.

## Шаги и результат

1. Проверен референс режима `Сегодня`. Состояние здоровое: вкладки находятся на белой подложке, примыкают к тулбару без зазора и используют темный нижний индикатор.
2. Проверена исходная реализация `Метрик`. Найдено расхождение: зазор `16px`, прозрачная подложка на сером фоне, синий активный текст `13px` и индикатор `3px`.
3. Внутренние вкладки метрик приведены к контракту табов приоритета: белая полноширинная подложка, зазор `0px`, горизонтальный `padding: 22px`, текст `14px`, темный активный текст и индикатор `4px`.
4. Проверено переключение вкладок. `aria-selected` обновляется, состояние-заглушка `Проектирование` отображается, возврат к `Общие` работает.

## Итог

Основное визуальное расхождение устранено. Строка вкладок метрик воспринимается как нижний уровень навигации верхней панели, а не как отдельный элемент внутри серого содержимого.

## Ограничения

Снимки встроенного браузера сохраняются плитками; для сравнения использован первый репрезентативный фрагмент. Геометрия, цвета, размеры и состояние вкладок дополнительно проверены через DOM и вычисленные стили. Полная проверка контраста и клавиатурной навигации на всех браузерах этим проходом не выполнялась.
