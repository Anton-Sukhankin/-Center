# NavigationTreeItem

## Назначение и граница

`NavigationTreeItem` отображает одну строку левого дерева навигации для бизнес-юнита, проекта или очереди. Компонент отвечает за HTML строки, визуальное состояние выбора и trigger выбора/раскрытия. Он не хранит дерево, не выбирает данные контекста и не перерисовывает соседние области.

## Реализация и стили

- `navigation-tree-item.js` — renderer и публичные функции компонента;
- `src/styles/global.css` — общие стили `.tree-node`, `.tree-item`, `.tree-icon`, `.tree-item-text` и уровней вложенности;
- `src/app/app.js` — рекурсивная сборка дерева и обработчики действий;
- `src/data/project-structure.js` — источник структуры и идентификаторов.

Автоматического теста компонента сейчас нет.

## Текущая реализация

### Входы

`renderNavigationTreeItem(params)` использует:

| Поле | Текущий смысл |
| --- | --- |
| `level` | Уровень вложенности в `data-level`. |
| `type` | `bu`, `project` или `queue`; определяет иконку и leaf-состояние. |
| `id` | Идентификатор выбранного или раскрываемого узла. |
| `title` | Единственный видимый текст строки. |
| `isSelected` | Добавляет класс `selected`. |
| `hasChildren` | Разрешает вызов `toggleTreeNode`; для leaf останавливает всплытие клика по иконке. |
| `isExpanded` | Выбирает иконку раскрытой или закрытой папки. |
| `currentProjectId` | Передается в `setActiveEntity` для адресации очереди к родительскому проекту. |

### Структура

Компонент возвращает открывающую часть `.tree-node`, строку `.tree-item`, иконку и `.tree-item-text`. Закрывающая часть вложенного контейнера возвращается отдельно через `renderNavigationTreeItemClose()`, потому что дочерние строки добавляет `src/app`.

Текущая строка отображает только иконку и `title`. Изображение, руководитель, стадия, кластер, регион и ТЭП не являются текущими входами или видимыми зонами этого компонента.

### Поведение и состояния

- Клик по строке вызывает `setActiveEntity(type, id, currentProjectId)`.
- Клик по иконке родительского узла вызывает `toggleTreeNode(id, event)`.
- `selected` показывает активный контекст.
- `expanded` и `collapsed` выражаются иконкой папки и наличием дочернего контейнера, которым управляет `src/app`.
- Очередь получает leaf-иконку и не раскрывает дочерние элементы.

Текущая строка реализована как `div` с inline `onclick`; собственные keyboard-обработчики и семантика `treeitem` в компоненте отсутствуют. Это ограничение текущего прототипа, а не разрешение считать строку клавиатурно доступной.

### Межкомпонентный контракт

| Источник | Условие | Результат | Получатель |
| --- | --- | --- | --- |
| `src/app` | Рендер дерева | Передает параметры узла | `NavigationTreeItem` |
| Строка дерева | Пользователь выбирает узел | Вызывается `setActiveEntity` | `src/app`, затем header, события, метрики и feature-поверхности |
| Иконка родителя | Пользователь раскрывает/сворачивает узел | Вызывается `toggleTreeNode` | Дочерний контейнер дерева |

## Будущая модель

Расширенная продуктовая строка может показывать дополнительные атрибуты:

| Уровень | Возможные целевые параметры |
| --- | --- |
| Бизнес-юнит | Изображение или визуальная метафора, руководитель, наличие проектов. |
| Проект | Миниатюра, стадия, кластер, регион, руководитель проекта. |
| Очередь | ТЭП, продаваемая площадь, стадия РНС/ЗОС/РВЭ. |

До отдельной реализации эти параметры принадлежат целевой модели `docs/entity-model.md` и не должны передаваться renderer только ради соответствия документации. Семантическое дерево, keyboard-навигация и focus-management также требуют отдельного изменения runtime и acceptance.

## Публичный интерфейс и зависимости

- `window.SCenterUI`;
- `window.SCenterComponents.renderNavigationTreeItem`;
- `window.SCenterComponents.renderNavigationTreeItemClose`;
- `window.setActiveEntity`;
- `window.toggleTreeNode`.

## Acceptance

Ручная проверка:

1. Бизнес-юнит и проект раскрываются и сворачиваются без выбора соседнего узла при клике по иконке.
2. Клик по строке выбирает правильный business unit, project или queue.
3. Выбранная строка получает `selected`, а header и активные данные соответствуют контексту.
4. Очередь использует родительский `projectId` и не получает устаревшие данные другой очереди.
5. Текст и идентификаторы экранируются renderer-функциями `SCenterUI`.

Автоматическое покрытие: отсутствует; при изменении renderer рекомендуется добавить локальный `*.test.mjs` для escaping, параметров действий и состояний иконки.

## Когда обновлять документ

Документ обновляется при изменении входов, структуры строки, выбора/раскрытия, стилей дерева, keyboard/focus поведения, публичных функций или влияния выбора на пользовательский путь. При изменении связности также проверяются `docs/context-behavior.md`, `docs/component-map.md`, `docs/component-impact-map.md` и `docs/system-compliance-matrix.md`.
