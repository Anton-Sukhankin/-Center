# Задачи следующего этапа

## Текущее состояние

- Первый структурный проход сохраняет текущий подход на обычных HTML/CSS/JS без сборщика и ES-модулей.
- Порядок загрузки скриптов и глобальные браузерные интерфейсы намеренно не изменялись.
- Поврежденная русская кодировка оставлена для отдельного этапа восстановления текстов.

## Карта будущей декомпозиции `src/app/app.js`

- Данные: моковые события, дерево проектов, финансовые метрики.
- Навигация: дерево проектов, выбор активной сущности, поиск по левому меню.
- Лента событий: фильтрация, вкладки, карточки, закрепление и скрытие.
- Детальная карточка события: drawer, параметры события, действия, график влияния.
- Метрики: строительные показатели, финансовое дерево, активная метрика, открытие BI-графика.

## Внешние зависимости

- `lucide` подключается через CDN и отвечает за иконки.
- `Chart.js` подключается через CDN, хотя текущая активная BI-визуализация в основном строится собственным SVG-кодом.
- Google Fonts подключает `Inter`; в `src/features/bi/bi-modal-v2.css` дополнительно импортируется `JetBrains Mono`.
