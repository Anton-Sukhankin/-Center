# Референс раздела «Объекты»

## Назначение

Каталог хранит исходный визуальный источник для активного feature `Объекты`. Временный изолированный стенд удален после переноса и продуктовой приемки основного прототипа.

## Источник истины

- `source-reference.png` — предоставленный пользователем desktop-референс.
- `../digital-chessboard/object-cards-and-metrics.png` — дополнительный внутренний источник для карточек переключения объектов: стилистика и состав `название / тип / факт / отклонение от плана / структура`.

## Используемые области

- карточки выбора дома;
- параметры выбранного объекта и готовность;
- вкладки и группа инструментов;
- двухстрочный header таблицы;
- двухуровневая иерархия `Группа работ → Вид работ`;
- progress bar, статусы и итоговая строка.

## Исключенные области

- глобальный белый header референса;
- профиль пользователя;
- левый sidebar;
- отдельная навигация референса;
- блок `Связи с ОС` до отдельного продуктового решения.

Референс является визуальным источником, но не подтверждает формулу агрегирования готовности, формат экспорта, состав меню строк или наличие третьего уровня `Работа`.
