# NavigationTreeItem

## Назначение и граница

`NavigationTreeItem` отображает одну строку левого дерева навигации для бизнес-юнита, проекта или очереди. Компонент отвечает за HTML строки, визуальное состояние выбора и trigger выбора/раскрытия. Он не хранит дерево, не выбирает данные контекста и не перерисовывает соседние области.

## Реализация и стили

[ContextBranch и Sidebar](../../../react/app/Shell.jsx) строят дерево из `src/data/project-structure.js`. Общие стили — `src/styles/global.css`.

## Текущая реализация

### Структура и вид

`ContextBranch` строит строку `.tree-item` из `node`, текущего выбора, глубины и карты раскрытия. Дочерний контейнер выводится только у раскрытой ветви. Ветка обозначается открытой или закрытой папкой, конечная очередь — иконкой корпуса. В строке нет фотографии или вторичных атрибутов проекта.

Во всех сегментах сводного дашборда левая панель имеет нейтральный фон, белое округлое поле поиска высотой `40px` и круглую кнопку с двойной стрелкой `38 × 38px` справа от поля, в той же строке с зазором `8px`. У поля поиска и кнопки одинаковая сплошная рамка `1px solid #D2D3D7` по всему контуру. Начало строки — в `16px` от нижней границы глобального хедера. В свёрнутом состоянии кнопка центрируется в панели. Положение кнопки, состояние панели, поиск, выбор и раскрытие ветвей сохраняются при переключении сегментов.

### Поведение и состояния

- Кнопка названия вызывает `onSelect(type, id)`.
- Кнопка папки вызывает `onToggle`, не выбирая контекст.
- Наведение затемняет фон строки: заливка получается смешиванием цвета панели с 5% чёрного. Выбранная строка `selected` сохраняет ту же заливку после ухода курсора, а её иконка становится синей (`--ui-accent` в тёмной теме). У строки только под курсором иконка остаётся нейтральной. Клавиатурный фокус отображается отдельно; при уменьшении движения переход отключается.
- Раскрытие отражается состоянием `aria-expanded` и видом папки. Кнопки выбора и раскрытия доступны с клавиатуры; пиктограмма очереди не интерактивна.
- В свёрнутой панели поиск и дерево недоступны для обхода, кнопка раскрытия остаётся доступна и не теряет фокус.

Прототип использует обычные кнопки, а не составную семантику `role="tree"` с навигацией стрелками.

### Межкомпонентный контракт

| Источник | Условие | Результат | Получатель |
| --- | --- | --- | --- |
| `src/app` | Рендер дерева | Передает параметры узла | `NavigationTreeItem` |
| Строка дерева | Пользователь выбирает узел | Вызывается `onSelect` | `src/app`, затем header, события, метрики и feature-поверхности |
| Иконка родителя | Пользователь раскрывает/сворачивает узел | Вызывается `onToggle` | Дочерний контейнер дерева |

## Будущая модель

Расширенная продуктовая строка может показывать дополнительные атрибуты:

| Уровень | Возможные целевые параметры |
| --- | --- |
| Бизнес-юнит | Изображение или визуальная метафора, руководитель, наличие проектов. |
| Проект | Миниатюра, стадия, кластер, регион, руководитель проекта. |
| Очередь | ТЭП, продаваемая площадь, стадия РНС/ЗОС/РВЭ. |

До отдельной реализации эти параметры принадлежат целевой модели `docs/entity-model.md`. Переход на составную семантику дерева с навигацией стрелками относится к отдельному этапу; существующие кнопки уже поддерживают клавиатуру.

## Публичный интерфейс и зависимости

`ContextBranch` принимает узел, глубину, запрос, текущий выбор и карту раскрытия. `onToggle` меняет ветвь, а `onSelect` передает тип и ID в App. Режим поиска временно раскрывает совпадающие ветви.

## Acceptance

Ручная проверка:

1. Бизнес-юнит и проект раскрываются и сворачиваются без выбора соседнего узла при клике по иконке.
2. Клик по строке выбирает правильный business unit, project или queue.
3. Выбранная строка получает `selected`, сохраняет более тёмную заливку без наведения и выделяет иконку синим. Header и активные данные соответствуют выбранному контексту.
4. Очередь использует родительский `projectId` и не получает устаревшие данные другой очереди.
5. Названия и идентификаторы передаются как React-данные.

Переходы между проектом, очередью и бизнес-юнитом проверяются в [браузерном сценарии](../../../scripts/check-react-browser.mjs).
