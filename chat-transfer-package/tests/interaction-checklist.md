# Чек-лист приёмки после переноса

## Запуск

- [ ] Компонент инициализируется без ошибок консоли.
- [ ] Открывается штатной кнопкой целевого проекта.
- [ ] Повторный вызов `init()` не требуется при каждом открытии.
- [ ] Клик вне панели закрывает чат.

## Чаты

- [ ] Переключение между чатами сохраняет отдельные истории.
- [ ] Новый чат создаётся с контекстом целевого проекта.
- [ ] Переименование обновляет заголовок.
- [ ] Удаление активного чата корректно выбирает следующий.
- [ ] Список разворачивается и сворачивается без скачка ленты.

## Сообщения

- [ ] `Enter` отправляет, `Shift+Enter` переносит строку.
- [ ] Высота textarea растёт и ограничивается.
- [ ] Во время запроса виден индикатор ожидания.
- [ ] Markdown: жирный текст, списки, заголовки и inline-code отображаются корректно.
- [ ] Ошибка API показывает системное сообщение.
- [ ] Action-кнопка передаёт `actionId`, `actionType` и `rowId` адаптеру.

## Интеграция

- [ ] Контекст обновляется при смене документа/выбранного объекта.
- [ ] История загружается и сохраняется выбранным способом.
- [ ] Вложения открывают механизм целевого проекта.
- [ ] Открытие чата закрывает конфликтующую боковую панель.
- [ ] Стили целевого проекта не меняют пузыри, кнопки и модальные окна чата.

## Визуальная проверка

- [ ] Проверены viewport `1440×900`, `1024×768` и ширина до `880px`.
- [ ] Проверены стандартная, минимальная и максимальная ширина панели.
- [ ] Состояния сопоставлены с `docs/behavior-contract.md` и эталонами из `docs/screenshots/`.
