# Карта будущей декомпозиции `src/app/app.js`

## Цель

Разделить большой файл `src/app/app.js` только после стабилизации текущей логики. Проект по-прежнему работает на обычных `<script>` без ES-модулей и без сборщика.

Первым устойчивым слоем выделен `src/data/app-data.js`. Он хранит атрибутивные данные событий и финансовых метрик, а также функции получения кратких и расширенных представлений.

## Зоны ответственности

| Зона | Что входит | Текущий статус |
| --- | --- | --- |
| Данные приложения | События, источники событий, приоритеты, финансовые метрики, представления сущностей. | Вынесено в `src/data/app-data.js` для событий и метрик. |
| Базовый UI-слой | Нейтральные хелперы и строительные блоки интерфейса. | Создан `src/ui/ui-core.js`; функции доступны через `window.SCenterUI`. |
| Компоненты интерфейса | Предметные повторяемые элементы: строки навигации, карточки метрик, карточки событий. | Созданы первые компоненты в `src/components`; функции доступны через `window.SCenterComponents`. |
| Навигация проекта | Дерево бизнес-юнитов, проектов и очередей, выбор активной сущности, поиск слева. | Пока остается в `src/app/app.js`. |
| Лента событий | Фильтрация, вкладки, счетчики, карточки, закрепление, скрытие и возврат событий. | Использует данные из `src/data/app-data.js`, но логика рендера остается в `src/app/app.js`. |
| Детальная карточка события | Drawer события, параметры, описание, действия, карточка влияния на метрику. | Использует расширенное представление события из слоя данных. |
| Фильтры | Источники, приоритет, период и дерево метрик. | Источники и метрики берутся из общего слоя данных. |
| Метрики | Правая панель, дерево метрик, активная метрика, открытие BI-графика, пересчет прогнозов. | Дерево метрик вынесено в слой данных; рендер и навигация остаются в текущих файлах. |
| Общие утилиты | Форматирование валюты, поиск сущностей, генерация мини-графиков. | Можно выделять после отделения навигации и рендера. |

## Минимальный безопасный порядок

1. Закрепить слой данных для событий и метрик.
2. Перенести проектную навигацию в отдельную область только после проверки ленты событий.
3. Вынести рендер ленты событий и карточки события.
4. Вынести drawer события.
5. Вынести правую панель метрик и сервис пересчета.

## Ограничения

- Не менять публичные `window.*` интерфейсы до отдельного решения о модульной архитектуре.
- Не смешивать декомпозицию с восстановлением поврежденной русской кодировки.
- Не менять визуальную концепцию интерфейса при переносе данных.
- Проверять каждый перенос через синтаксическую проверку JS и ручные сценарии интерфейса.
